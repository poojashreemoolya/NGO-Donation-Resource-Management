# NGO Donation and Resource Management System

A web-based donation and resource management system developed for Inchara Foundation.

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Modules

1. Donation Management
2. Resource and Inventory Management
3. Volunteer and Beneficiary Management
4. Main Website, Dashboard and Reports

## Project Objective

To simplify the management of donations, resources, volunteers and beneficiaries through a centralized system.
